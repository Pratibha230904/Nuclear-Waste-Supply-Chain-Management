# Nuclear Waste Supply Chain Management

## About the Project

A blockchain-based system designed to securely track and monitor nuclear waste throughout its supply chain.

## My Contribution

- Worked on blockchain-based waste tracking
- Implemented QR-based drum identification
- Worked on role-based access control
- Worked on supply-chain traceability
- Integrated IoT-based monitoring
- Worked on temperature and gas alerts

## Technologies Used

- Java
- Hyperledger Fabric
- Blockchain
- QR Code
- IoT

## Key Features

- Secure waste tracking
- QR-based drum identification
- Blockchain-based records
- Role-based access control
- IoT monitoring
- Temperature and gas alerts
- End-to-end traceability

## Objective

To improve the security, transparency, and traceability of nuclear waste management from generation to final disposal.
